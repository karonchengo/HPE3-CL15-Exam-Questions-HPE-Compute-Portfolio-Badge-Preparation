## **What Is the HPE3-CL15 Compute Portfolio Exam?**

HPE3-CL15 is a continuous learning badge examination that evaluates candidates' understanding of HPE's compute portfolio, product capabilities, and solution positioning.

Unlike a traditional technical certification exam that focuses primarily on configuration and troubleshooting, the Compute Portfolio Exam emphasizes knowledge of HPE products and their business and technical applications.

Candidates should understand the different HPE compute product families, their key capabilities, and how to identify suitable solutions for different customer requirements.

This badge has two important purposes:
- **Certification requirement:** It is a required badge examination in the HPE ATP – Compute Solutions certification path.
- **Partner program requirement:** It is also required for the HPE Partner Ready Vantage Program.

For HPE partners, completing this examination helps demonstrate familiarity with HPE compute offerings and supports their broader certification and partner program objectives.

## **Where HPE3-CL15 Fits in the HPE ATP – Compute Solutions Path**

The HPE ATP – Compute Solutions certification validates foundational knowledge of HPE compute technologies and solutions.

HPE's published certification requirements identify four required examinations for this certification:

| Requirement               | Exam Code | Exam Name                          |
| ------------------------- | --------- | ---------------------------------- |

| Continuous Learning Badge | HPE3-CL16 | Compute Management Exam            |
| Continuous Learning Badge | HPE3-CL17 | Cloud Foundations for Compute Exam |

HPE3-CL15 is therefore not a standalone replacement for HPE0-S61. It is one of three required continuous learning badge examinations that complement the main HPE Compute Fundamentals examination.

Completing these requirements helps candidates establish a broader understanding of HPE compute products, management technologies, and cloud-related compute solutions.

## Key HPE Compute Portfolio Knowledge Areas

Candidates preparing for the HPE3-CL15 exam should become familiar with the following areas of HPE's compute portfolio, management technologies, and infrastructure solutions.

### 1. HPE Compute Portfolio and Server Components

Understand HPE's main compute product families, including HPE ProLiant servers and other enterprise compute platforms. Focus on their key components, capabilities, and positioning for different customer workloads and infrastructure requirements.

### 2. HPE iLO and Server Management Features

Learn how HPE iLO supports remote server administration, hardware monitoring, and management. Review related server capabilities such as Secure Boot, UEFI configuration, and Intelligent Provisioning.

### 3. HPE Compute Management Solutions

Become familiar with HPE Compute Ops Management, HPE OneView, and HPE iLO. Understand their respective roles in infrastructure administration, server monitoring, and managing HPE compute environments.

### 4. HPE Compute Solution Design and Pre-Sales Tools

Understand how HPE tools support customer requirement analysis, infrastructure sizing, power planning, and solution configuration. Important resources include HPE Power Advisor, HPE Solution Sizer, HPE One Config Advanced, and the HPE Demonstration Portal.

### 5. Server Deployment and Workload Management

Review key server lifecycle activities, including deployment, workload profiles, firmware updates, and power monitoring. Become familiar with Service Pack for ProLiant (SPP), HPE iLO firmware management, and Workload Advisor capabilities.
